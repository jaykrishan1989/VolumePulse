Connect your IBKR Gateway

This app never asks for your IBKR username or password. Log into IBKR Gateway (or TWS) on this computer, then enter the API socket below.

  1. Open IBKR Gateway and sign in with your own account (2FA stays in their app).
  2. Configuration → API → Settings: enable socket clients, port 4001 live or 4002 paper.
  3. Trusted IP 127.0.0.1. Read-Only API can stay on.
